Buatkan saya project github yg bernama "Ximi Ultimate Tool". Ximi Ultimate Tool adalah sebuah tool android yg berfokus kepada pengoperasian adb dan fastboot seperti debloater otomatis, debloat manual, logcat, dmesg, root explorer (root only), terminal shell android, fastboot flasher. Ximi Ultimate Tool memiliki design MIUIX di GUI nya. Ximi Ultimate tool juga compatible dengan Windows dan Linux. Ximi Ultimate Tool juga memiliki 2 opsi bahasa yaitu Bahasa inggris, Bahasa indonesia

Fitur-fitur dari Ximi Ultimate tool:

1) Debloater
    Fitur ini memiliki fitur debloat secara otomatis dan manual. Jika user memilih fitur debloat secara otomatis, mereka bisa unchecklist beberapa app yang masih diperlukan

2) Root Explorer
    Fitur ini bisa menjelajahi direktori android dengan root mode dan memiliki ability create file, add file, rename file, copy file, move file, extract zip, push file from pc, pull file from android. Root explorer juga kompatibel dengan non root, tapi terbatas dibandingkan dengan root mode

3) Terminal shell
    Bisa menggunakan terminal shell android sebagai root ataupun shell dengan tambahan custom command "fastfetch" seperti di linux dengan icon hyperos

4) Fastboot flasher
     Fitur ini berfungsi sebagai flasher partisi tertentu seperti boot,vendor_boot/recovery,vbmeta,vbmeta_system,vbmeta_vendor dan juga sebagai pengganti mi flash yg terkenal banyak masalah seperti opsi defaultnya ngunci bootloader sehingga user gk sadar. Dengan adanya Ximi Ultimate Tool, User bisa memilih clean flash, clean flash without format data, atau clean flash + lock bootloader dan juga memiliki opsi advance mode yang dimana user bisa unchecklist partisi yang dia tidak ingin flash seperti preloader dengan cara mengomentari script flashernya dan bikin log output flashnya secara real time

Konsep Interface UI
Mengusung tema MIUIX. Design main interfacenya memiliki floating bottom bar seperti iOS 26 dengan liquid glassnya. Menu dari floating bottom barnya yaitu ADB,Fastboot ,Terminal, Explorer dan Settings. Saat device connect ke adb, muncul nama devices, versi android, dan juga versi hyperos(baca dari property ro.mi.os.version.incremental) di Menu Settingsnya dan menggunakan design seperti yang ada di "example.png", menambahkan konfigurasi bahasa, menambahkan konfigurasi tema seperti mengganti light/dark mode, mengganti background interface, menambahkannya sebuah link github yaitu https://github.com/iprjkt dan link telegram yaitu https://t.me/anotherside551
